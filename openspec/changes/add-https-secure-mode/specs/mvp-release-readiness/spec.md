## MODIFIED Requirements

### Requirement: MVP использует явно ограниченную LAN-only модель

Публичный MVP 1.0 MUST использовать одно Android-приложение и локальный transport только в доверенной сети: HTTP/WebSocket в обычном режиме или HTTPS/WSS в необязательном защищённом режиме. Продукт MUST NOT заявлять шифрование локального трафика в обычном режиме. Шифрование MAY заявляться только для защищённого режима и только на странице, фактически открытой по HTTPS. Продукт MUST NOT заявлять работу через интернет, облачный relay или наличие desktop companion. Ограничение транспорта в обычном режиме и рекомендация не передавать чувствительные данные в публичной либо чужой сети MUST быть доступны пользователю до начала передачи.

#### Scenario: Пользователь готовится передать данные

- **WHEN** пользователь запускает сервер в обычном режиме либо открывает web-интерфейс по HTTP перед первой передачей
- **THEN** интерфейс сообщает, что соединение работает только в локальной доверенной сети и HTTP не шифрует трафик
- **AND** предупреждение не маскируется формулировкой о полной безопасности или защищённом канале

#### Scenario: Интернет недоступен

- **WHEN** телефон и компьютер находятся в одной локальной сети без доступа в интернет
- **THEN** основные pairing, text и file flows остаются доступны в обоих режимах
- **AND** приложение не требует облачной учётной записи, relay или внешнего backend

#### Scenario: Пользователь работает в защищённом режиме

- **WHEN** web-интерфейс открыт по HTTPS с сертификатом, подписанным корнем телефона
- **THEN** интерфейс может сообщить, что соединение зашифровано
- **AND** не заявляет работу через интернет или защиту за пределами локальной сети
