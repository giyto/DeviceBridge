## ADDED Requirements

### Requirement: Папка записывается в историю одной записью

Законченная папка MUST записываться в локальную историю одной записью: имя созданной на телефоне папки, число сохранённых файлов, общее число файлов, общий размер, итог и браузер-отправитель. Файлы папки MUST NOT записываться в историю по отдельности. Запись папки MUST подчиняться тому же сроку хранения и тем же правилам удаления, что и остальные записи. Существующие записи истории MUST сохраняться при обновлении приложения.

#### Scenario: Папка в истории

- **WHEN** папка «Фото» закончилась с итогом «118 из 120, 2 с ошибкой»
- **THEN** в истории одна запись «Фото» с 118 из 120 файлов, общим размером и итогом

#### Scenario: Повтор обновляет запись

- **WHEN** после «Повторить» оба файла дошли
- **THEN** та же запись показывает 120 из 120, новая запись не появляется

#### Scenario: Обновление приложения

- **WHEN** приложение обновлено до версии с папками
- **THEN** все прежние записи истории остаются на месте
