## ADDED Requirements

### Requirement: Входящая папка показывается одним уведомлением

Когда приложение не на экране, Android MUST показывать о входящей папке одно уведомление с именем папки, числом файлов и общим размером, с кнопками «Принять» и «Отклонить» по тем же правилам, что и уведомление о входящих файлах. «Принять» MUST принимать всю папку в выбранное место сохранения, а если оно не выбрано, MUST открывать приложение для выбора. После окончания папки Android MUST показывать одно уведомление об итоге папки. Файлы папки MUST NOT создавать уведомлений по отдельности.

#### Scenario: Папка из уведомления

- **WHEN** приложение свёрнуто, место сохранения выбрано, а браузер предложил папку «Фото» из 120 файлов
- **THEN** появляется одно уведомление «Папка "Фото": 120 файлов, 3,4 ГиБ» с «Принять» и «Отклонить»
- **AND** «Принять» принимает всю папку без открытия приложения

#### Scenario: Итог папки

- **WHEN** папка закончилась, пока приложение свёрнуто
- **THEN** появляется одно уведомление с итогом папки, например «Папка "Фото": сохранено 118 из 120»
