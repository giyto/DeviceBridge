## ADDED Requirements

### Requirement: Web shell позволяет выбрать или перетащить папку

Web shell MUST давать выбрать папку отдельной кнопкой «Выбрать папку» и принимать папку, перетащенную в область файлов, вместе с файлами или отдельно. Web shell MUST обходить все вложенные папки и передавать для каждого файла путь относительно выбранной папки. Служебные файлы `desktop.ini`, `Thumbs.db` и `.DS_Store` и пустые папки MUST NOT передаваться. Файлы больше действующего предела одного файла MUST NOT передаваться, а карточка папки MUST называть их число и первые имена. Папка MUST показываться в черновике одной карточкой с именем, числом файлов и общим размером, и её MUST можно убрать из черновика целиком. Если папка превышает пределы папки, web shell MUST показать причину в карточке и MUST NOT начинать передачу этой папки.

#### Scenario: Выбрана папка

- **WHEN** пользователь нажал «Выбрать папку» и выбрал папку «Фото» с подпапками
- **THEN** черновик показывает одну карточку «Фото» с числом файлов и общим размером
- **AND** файлы подпапок входят в папку с их путями

#### Scenario: Перетащены папка и файл

- **WHEN** пользователь перетащил в окно папку «Документы» и файл `счёт.pdf`
- **THEN** черновик показывает карточку папки «Документы» и отдельную карточку файла `счёт.pdf`

#### Scenario: В папке служебные файлы и слишком большой файл

- **WHEN** в папке есть `Thumbs.db`, пустая подпапка и видео больше предела одного файла
- **THEN** `Thumbs.db` и пустая подпапка не считаются и не передаются
- **AND** карточка папки пишет, что один файл больше предела и не будет отправлен, и называет его

#### Scenario: Папка больше пределов

- **WHEN** в выбранной папке 2500 файлов
- **THEN** карточка папки пишет, что в папке больше 2000 файлов
- **AND** эту папку отправить нельзя, остальные элементы черновика отправляются

### Requirement: Web shell показывает прогресс и итог папки

Во время передачи папки web shell MUST показывать одну карточку папки с числом сохранённых файлов из общего, общим прогрессом, именем текущего файла и кнопкой отмены всей папки. Каждый файл MUST хешироваться непосредственно перед своей отправкой, а не все файлы папки заранее. После окончания карточка MUST показывать итог: сохранено из общего, число ошибок или причину остановки, и «Повторить», если есть не сохранённые файлы и повтор доступен.

#### Scenario: Идёт передача папки

- **WHEN** передаётся 41-й файл из 120
- **THEN** карточка показывает «40 из 120», общий прогресс и имя текущего файла

#### Scenario: Папка закончилась с ошибками

- **WHEN** папка закончилась, 2 файла из 120 прочитать не удалось
- **THEN** карточка показывает «118 из 120, 2 с ошибкой» и кнопку «Повторить»

#### Scenario: Отмена со страницы

- **WHEN** пользователь нажал отмену на карточке папки
- **THEN** передача папки останавливается на обеих сторонах
- **AND** карточка показывает, сколько файлов уже сохранено
