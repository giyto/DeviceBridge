## MODIFIED Requirements

### Requirement: Настройки сохраняются локально и валидируются

Android-приложение MUST хранить имя телефона, имя в сети, retention period, выбранную папку сохранения, пользовательский file size limit, признак автоприёма файлов от запомненных браузеров и время автоостановки сервера между перезапусками процесса. Имя MUST быть непустым после trim, не длиннее 40 Unicode code points и не содержать управляющих символов. Имя в сети MUST соответствовать правилам требования «Пользователь задаёт имя в сети» и MUST по умолчанию равняться `devicebridge`. File size limit MUST быть больше нуля и MUST NOT превышать hard limit 1 073 741 824 байта. Автоприём MUST быть выключен по умолчанию; включить его MUST быть возможно только при выбранной доступной default destination, а при потере доступа к папке автоприём MUST считаться неактивным до выбора доступной папки. Время автоостановки MUST принимать только значения «выключено», 15, 30 или 60 минут и MUST по умолчанию равняться 30 минутам.

#### Scenario: Пользователь меняет имя телефона
- **WHEN** введено допустимое имя и пользователь сохраняет настройку
- **THEN** Android и последующие browser sessions показывают нормализованное имя
- **AND** значение сохраняется после пересоздания Activity и процесса

#### Scenario: Пользователь меняет имя в сети
- **WHEN** введено допустимое имя в сети и пользователь сохраняет настройку
- **THEN** значение сохраняется в нижнем регистре после пересоздания Activity и процесса
- **AND** сохранённое недопустимое значение при чтении заменяется значением `devicebridge`

#### Scenario: Указан недопустимый лимит
- **WHEN** пользователь пытается сохранить нулевой лимит или значение выше 1 ГиБ
- **THEN** настройка отклоняется с понятным сообщением
- **AND** прежнее допустимое значение продолжает действовать

#### Scenario: Настройки ещё не создавались
- **WHEN** приложение впервые читает settings storage
- **THEN** срок хранения равен 30 дням, file limit равен проверенному hard limit, custom destination отсутствует, автоприём выключен, автоостановка равна 30 минутам, а имя в сети равно `devicebridge`
- **AND** экран не показывает вымышленные trusted browsers

#### Scenario: Пользователь включает автоприём
- **WHEN** default destination выбрана и доступна, а пользователь включает автоприём
- **THEN** настройка сохраняется и применяется к следующим offers trusted sessions
- **AND** Settings поясняет, что автоприём действует только для запомненных браузеров

#### Scenario: Папка для автоприёма не выбрана
- **WHEN** default destination отсутствует
- **THEN** включение автоприёма недоступно, а Settings объясняет, что сначала нужно выбрать папку
- **AND** сохранённое значение автоприёма не становится включённым

#### Scenario: Папка для автоприёма стала недоступна
- **WHEN** автоприём включён, а доступ к default destination отозван
- **THEN** Settings показывает, что автоприём приостановлен до выбора доступной папки
- **AND** после выбора доступной папки автоприём снова действует без повторного включения

#### Scenario: Пользователь меняет время автоостановки
- **WHEN** пользователь выбирает «выключено», 15, 30 или 60 минут
- **THEN** значение сохраняется и применяется к работающему серверу без перезапуска, а отсчёт простоя начинается заново
- **AND** сохранённое значение вне допустимого набора при чтении заменяется значением по умолчанию
