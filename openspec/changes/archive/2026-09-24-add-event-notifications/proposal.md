## Why

Сейчас о новом событии можно узнать, только глядя на нужный экран. Телефон показывает лишь постоянное уведомление «Сервер запущен», поэтому запрос на подключение, входящие файлы и текст с компьютера остаются незамеченными, пока человек сам не откроет приложение. Страница на компьютере системных уведомлений не показывает, и текст или файлы с телефона теряются в свёрнутой вкладке. После появления защищённого режима страница по HTTPS стала защищённым контекстом, и браузер разрешает ей системные уведомления, так что закрыть этот пробел теперь можно без внешних сервисов.

## What Changes

- **Компьютер (страница в Chrome или Edge):**
  - системные уведомления через Notification API без service worker и без Web Push: внешние push-сервисы Google или Microsoft противоречат принципу «только локальная сеть»;
  - события: текст или ссылка с телефона, файлы, предложенные телефоном, завершение или сбой передачи на телефон, потеря связи (сервер остановлен, вход отозван);
  - уведомление показывается, только если вкладка скрыта или окно не в фокусе; клик возвращает на вкладку и показывает нужный элемент;
  - кнопка «Включить уведомления»: браузер спрашивает разрешение только после нажатия; переключатель «Скрывать содержимое» (по умолчанию начало текста показывается); звук системный, своего нет;
  - системные уведомления работают только в защищённом режиме (HTTPS). По HTTP страница показывает счётчик новых событий в заголовке вкладки «(2) DeviceBridge» и подсказку «Уведомления доступны в защищённом режиме»;
  - уведомления приходят, пока вкладка открыта (можно в фоне или в свёрнутом окне). При закрытой вкладке уведомлений нет.
- **Телефон:**
  - новый канал уведомлений «События» с высокой важностью, отдельно от тихого канала «Сервер запущен»;
  - уведомления о событиях показываются, только когда приложение не на экране;
  - запрос подключения: уведомление только с кнопкой «Открыть», решение о доступе принимается в приложении;
  - входящие файлы: «Принять», если папка для сохранения уже выбрана, и «Отклонить»;
  - входящий текст: «Копировать», для ссылки ещё «Открыть»; на экране блокировки содержимое скрыто, видно только «Текст с компьютера»;
  - завершение или сбой передачи: итоговое уведомление с кнопкой «Показать»; автоприём от доверенного браузера даёт только итоговое уведомление;
  - новое разрешение не нужно: разрешение на уведомления уже запрашивается при запуске сервера.

Вне объёма: Web Push и уведомления при закрытой вкладке, собственные звуки, уведомления на Android-версии Chrome, подтверждение подключения прямо из шторки.

## Capabilities

### New Capabilities

- `event-notifications`: какие события порождают уведомления на телефоне и на компьютере, когда они показываются и когда нет, действия в уведомлениях, скрытие содержимого, разрешения браузера и Android, запасной вариант для HTTP-страницы.

### Modified Capabilities

Нет. Новые уведомления дополняют существующие требования и не меняют их: постоянное уведомление сервера остаётся прежним, web shell по-прежнему не регистрирует service worker и не обращается к внешним адресам.

## Impact

- **Android:** новый notifier событий в пакете `server` рядом с `AndroidServerNotificationController`, второй канал уведомлений, приёмник действий уведомлений (принять, отклонить, копировать), отслеживание, на экране ли приложение, открытие нужной вкладки из уведомления в `MainActivity`.
- **Android, источники событий:** запросы подключения (`BrowserSessionCoordinator`), входящие файлы и итоги передач (`FileTransferCoordinator`, `TrustedAutoAcceptController`), входящий текст (`TextTransferCoordinator`).
- **Web:** новый контроллер уведомлений и хранилище настроек в `localStorage`, подписка на события текста, файлов и соединения, кнопка и переключатель в интерфейсе, счётчик в заголовке вкладки.
- **Зависимости:** новых нет (при необходимости `androidx.lifecycle:lifecycle-process` из уже используемого семейства AndroidX Lifecycle).
- **Тесты:** JVM (правила показа и содержимое уведомлений, действия), Compose, web unit-тесты контроллера с поддельным Notification API, Playwright-проверки кнопки, счётчика и отсутствия service worker.
