## 7. Сквозная проверка

- [x] 7.1 E2E на эмуляторе: Chrome с `--ignore-certificate-errors-spki-list=<SPKI корня>` на отдельном профиле открывает `https://`, проходит pairing и передаёт текст и файл в обе стороны. Отдельно проверить, что без флага открывается страница установки по `http://`. Хранилище сертификатов хоста не менять
- [x] 7.2 Ручная проверка на компьютере пользователя после установки корня по инструкции: Edge и Яндекс Браузер открывают защищённую версию без предупреждения, сертификат «valid and trusted». Результат записан в design.md
