## MODIFIED Requirements

### Requirement: Пользователь получает достижимый локальный endpoint

После успешного запуска DeviceBridge MUST показывать browser URL с достижимым non-loopback IPv4-адресом подходящей локальной сети и фактически занятым свободным портом. Если телефон занял имя в локальной сети, показываемым URL MUST быть только адрес по этому имени; URL с IPv4-адресом MUST NOT показываться, пока имя занято. Показываемый URL MUST использовать схему `http://` в обоих режимах. В защищённом режиме этот адрес ведёт на страницу установки сертификата либо сразу на HTTPS, если браузер уже доверяет телефону, поэтому браузер без установленного сертификата не видит предупреждения об ошибке сертификата. В защищённом режиме UI MUST пояснять, что браузер сам откроет защищённое соединение. Пользовательский URL MUST NOT содержать `0.0.0.0` или loopback-адрес.

#### Scenario: Телефон подключён к Wi-Fi

- **WHEN** на телефоне доступен подходящий IPv4-адрес Wi-Fi LAN
- **THEN** сервер принимает локальные соединения на свободном порту
- **AND** UI и уведомление показывают копируемый URL с именем телефона, если оно занято, либо с IPv4-адресом, и этим портом

#### Scenario: Имя занято, адрес один

- **WHEN** сервер запущен и телефон занял имя в локальной сети
- **THEN** UI показывает URL `http://<имя>.local:<порт>`
- **AND** URL с IPv4-адресом не показывается

#### Scenario: Компьютер подключён к точке доступа телефона

- **WHEN** телефон предоставляет локальный IPv4 endpoint для своей точки доступа
- **THEN** DeviceBridge показывает адрес, достижимый клиентом этой точки доступа
- **AND** browser web shell открывается по показанному URL без интернета

#### Scenario: Подходящий адрес отсутствует

- **WHEN** система не может определить достижимый локальный IPv4 endpoint
- **THEN** сервер не начинает слушать произвольный интерфейс
- **AND** UI предлагает подключиться к Wi-Fi или включить точку доступа и повторить запуск

#### Scenario: Предпочтительный порт занят

- **WHEN** выбранный порт уже используется
- **THEN** DeviceBridge выбирает другой свободный порт либо показывает recoverable error
- **AND** никогда не показывает URL порта, который сервер фактически не занял

#### Scenario: Сервер запущен в защищённом режиме

- **WHEN** сервер успешно запущен при включённом защищённом режиме
- **THEN** UI и уведомление показывают URL со схемой `http://` и UI поясняет, что браузер сам откроет защищённое соединение
- **AND** браузер без установленного корня открывает по нему страницу установки без предупреждения о сертификате
- **AND** браузер с установленным корнем переходит по нему на HTTPS без предупреждения
