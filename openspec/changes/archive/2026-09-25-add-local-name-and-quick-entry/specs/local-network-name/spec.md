## Purpose

Постоянное имя телефона в локальной сети вида `devicebridge.local`: по нему браузер открывает DeviceBridge, даже когда IP-адрес телефона меняется. Спецификация описывает, когда телефон отвечает на имя, как он избегает чужих имён и как адрес по имени показывается пользователю.

## ADDED Requirements

### Requirement: Телефон отвечает на имя в сети только во время работы сервера

Пока сервер запущен, DeviceBridge MUST отвечать на запросы mDNS о своём занятом имени `<имя>.local` IPv4-адресом опубликованного endpoint. Отвечать он MUST только в той сети, где опубликован endpoint. DeviceBridge MUST NOT отвечать на запросы о других именах и MUST NOT объявлять DNS-SD службы. После остановки сервера, потери сети или смены адреса телефон MUST сообщить в сеть, что имя больше не действует, и прекратить ответы. Если телефон не может принимать запросы mDNS, сервер MUST продолжать работать по IP-адресу, а интерфейс MUST объяснять, что адрес по имени недоступен.

#### Scenario: Компьютер ищет имя телефона

- **WHEN** сервер запущен с именем `devicebridge.local`, и компьютер в той же сети спрашивает адрес этого имени
- **THEN** телефон отвечает текущим IPv4-адресом сервера
- **AND** браузер открывает `http://devicebridge.local:<порт>`

#### Scenario: Компьютер спрашивает IPv6-адрес имени

- **WHEN** компьютер спрашивает для занятого имени запись IPv6
- **THEN** телефон отвечает, что такой записи нет, и компьютер не ждёт тайм-аут перед использованием IPv4

#### Scenario: Сервер остановлен

- **WHEN** пользователь останавливает сервер или сервер останавливается из-за смены сети
- **THEN** телефон сообщает в сеть, что имя больше не действует
- **AND** больше не отвечает на запросы об этом имени

#### Scenario: Сеть не пропускает mDNS

- **WHEN** телефон не смог начать принимать запросы mDNS
- **THEN** сервер продолжает работать, а главным адресом показывается IP-адрес
- **AND** интерфейс сообщает, что адрес по имени сейчас недоступен

### Requirement: Телефон не занимает чужое имя

Перед тем как отвечать на имя, DeviceBridge MUST проверить в сети, что имя не занято другим устройством. Если желаемое имя занято, телефон MUST по порядку проверить имена с суффиксами от `-2` до `-9` и занять первое свободное. Если свободного имени нет, сервер MUST работать только по IP-адресу. Когда занятое имя отличается от желаемого, главный экран MUST объяснять, что желаемое имя занято другим устройством, и предлагать задать своё имя в настройках. Если во время работы другое устройство начинает отвечать на то же имя, телефон MUST перестать использовать имя до следующего запуска и показывать IP-адрес.

#### Scenario: Имя свободно

- **WHEN** в сети нет устройства с именем `devicebridge.local`
- **THEN** телефон занимает `devicebridge.local`

#### Scenario: Имя занято другим телефоном

- **WHEN** в сети уже есть устройство, отвечающее на `devicebridge.local`
- **THEN** телефон занимает `devicebridge-2.local`
- **AND** главный экран сообщает, что имя `devicebridge` занято другим устройством, и предлагает задать своё имя

#### Scenario: Все варианты имени заняты

- **WHEN** заняты желаемое имя и все варианты с суффиксами до `-9`
- **THEN** сервер запускается и показывает только IP-адрес
- **AND** главный экран объясняет, почему адреса по имени нет

#### Scenario: Конфликт во время работы

- **WHEN** во время работы другое устройство начинает отвечать на занятое телефоном имя
- **THEN** телефон перестаёт отвечать на это имя и показывает главным адресом IP-адрес
- **AND** при следующем запуске сервера снова проверяет желаемое имя

### Requirement: Пока имя занято, телефон доступен только по нему

Когда имя занято, главный экран и уведомление сервера MUST показывать единственный адрес `http://<имя>.local:<порт>` и MUST NOT показывать адрес по IP. Кнопка «Копировать адрес» MUST копировать адрес по имени. Пока имя занято, сервер MUST обслуживать только запросы с `Host` этого имени. Запрос страницы по IP-адресу MUST получать перенаправление на тот же путь по имени, а запросы API по IP-адресу MUST отклоняться. Если имя занять не удалось или оно потеряно во время работы, единственным адресом MUST становиться IP-адрес, и главный экран MUST объяснять почему. В защищённом режиме адрес по имени MUST использоваться только если корневой сертификат телефона допускает это имя.

#### Scenario: Сервер запущен с именем

- **WHEN** сервер запущен и занял имя `devicebridge.local`
- **THEN** главный экран и уведомление показывают только `http://devicebridge.local:8787`
- **AND** адрес по IP на экране не показывается

#### Scenario: Страница открыта по старому адресу с IP

- **WHEN** имя занято, а браузер открывает `http://192.168.0.90:8787/`
- **THEN** телефон перенаправляет его на `http://devicebridge.local:8787/`
- **AND** запрос API по IP-адресу получает отказ

#### Scenario: Имя недоступно

- **WHEN** сервер запущен без занятого имени
- **THEN** единственным адресом показывается IP-адрес, и сервер обслуживает запросы по нему
- **AND** главный экран объясняет, почему адреса по имени нет

### Requirement: Пользователь задаёт имя в сети

Настройки MUST содержать поле «Имя в сети» со значением по умолчанию `devicebridge`. Имя MUST состоять из латинских букв, цифр и дефиса, MUST иметь длину от 1 до 40 символов, MUST NOT начинаться или заканчиваться дефисом и MUST сохраняться в нижнем регистре. Недопустимое значение MUST отклоняться с понятным сообщением, а прежнее имя MUST продолжать действовать. Изменённое имя MUST начинать действовать со следующего запуска сервера. Если сервер запущен, настройки MUST сообщать об этом.

#### Scenario: Пользователь задаёт своё имя

- **WHEN** пользователь сохраняет имя `Nikita`
- **THEN** сохраняется имя `nikita`
- **AND** после следующего запуска сервера адрес становится `http://nikita.local:<порт>`

#### Scenario: Недопустимое имя

- **WHEN** пользователь вводит имя с пробелом, кириллицей, начальным дефисом или длиннее 40 символов
- **THEN** настройки объясняют допустимые символы и длину
- **AND** прежнее имя сохраняется

#### Scenario: Имя меняют при работающем сервере

- **WHEN** пользователь сохраняет новое имя, пока сервер запущен
- **THEN** настройки сообщают, что новый адрес заработает после перезапуска сервера
- **AND** текущий адрес продолжает работать до остановки сервера
