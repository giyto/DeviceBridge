## Why

Сейчас, чтобы открыть DeviceBridge на компьютере, нужно набрать IP-адрес телефона вида `192.168.1.37:8787`. Роутер время от времени выдаёт телефону другой адрес. Тогда закладка перестаёт открываться, а браузер «забывает» телефон: запомненный вход хранится отдельно для каждого точного адреса. Кроме того, открытая вкладка сдаётся после трёх быстрых попыток переподключения, а запрос подключения нельзя решить из уведомления. Всё это делает ежедневный вход дольше, чем нужно. Цель change: закладка плюс включённый сервер, и больше ничего вводить не нужно.

## What Changes

- **Постоянный адрес по имени.** Пока сервер запущен, телефон отвечает в локальной сети на имя `<имя>.local` по протоколу mDNS. По умолчанию имя `devicebridge`. Адрес на телефоне и в уведомлении сервера становится `http://devicebridge.local:8787`. Пока имя занято, это единственный вход: страница по IP перенаправляется на имя, API по IP отклоняется. Адрес по IP становится входом, только если имя занять не удалось.
- **Настройка «Имя в сети».** Пользователь может задать своё имя, например `nikita`. Допустимы латинские буквы, цифры и дефис. Новое имя начинает работать со следующего запуска сервера.
- **Два телефона в одной сети.** Перед тем как занять имя, телефон проверяет, не занято ли оно. Если занято, телефон берёт `имя-2`, `имя-3` и так далее. На главном экране он объясняет, что имя занято другим устройством, и предлагает задать своё. Если свободного имени не нашлось, телефон работает только по IP.
- **Сервер принимает запросы по имени.** Пока имя занято, проверки Host и Origin пропускают только его с портом; запрос страницы по IP перенаправляется на имя. Любые другие имена по-прежнему отклоняются.
- **HTTPS по имени.** Корневой сертификат новых установок разрешает все имена `.local` (раньше только `devicebridge.local`) и прежние частные диапазоны IPv4. Сертификат сервера содержит занятое имя. Старый корень продолжает работать для `devicebridge.local`. Если он не покрывает занятое имя, настройки предлагают один раз сбросить сертификат. **BREAKING** для уже установленного на компьютере корня: чтобы HTTPS работал с собственным именем, корень нужно переустановить. HTTPS ещё не выходил в релизе.
- **Вкладка подключается сама.** Если сервер остановлен или недоступен, открытая страница не сдаётся после трёх попыток. Она спокойно ждёт и сама входит по запомненному входу, как только сервер снова запущен. Если запомненного входа нет, она показывает форму кода с пометкой, что телефон снова доступен.
- **Понятный отказ запомненного входа.** Если телефон по адресу не принял запомненный вход, страница пишет «Этот телефон вас не узнал» и объясняет две возможные причины: браузер удалили из доверенных, или по этому адресу сейчас отвечает другой телефон.
- **«Запомнить этот браузер» включено по умолчанию.** Телефон по-прежнему отдельно спрашивает, запомнить ли браузер.
- **Решение запроса подключения из уведомления.** В уведомлении о запросе появляются «Отклонить», «Разрешить» и, если браузер попросил запомнить его, «Разрешить и запомнить». На Android 12 и новее кнопки разрешения требуют разблокировки телефона. На Android 10-11 такой защиты у кнопок нет, поэтому там остаётся «Отклонить», а разрешить можно только в приложении.

Не входит: подсказка установить страницу как приложение и пометка окна ярлыка (от них отказались при проверке), вход по QR-коду, сверка числа вместо кода, «Поделиться адресом», продление запомненного входа, адрес на плитке быстрых настроек (плитка не показывает адрес и сейчас).

## Capabilities

### New Capabilities
- `local-network-name`: имя телефона в локальной сети (mDNS). Как оно выбирается и проверяется на занятость, когда телефон отвечает и перестаёт отвечать, настройка «Имя в сети» и вход только по имени, пока оно занято.

### Modified Capabilities
- `server-lifecycle`: показываемый адрес сервера использует имя, а IP показывается, только когда имени нет. Смена сети и остановка также прекращают ответы на имя.
- `https-secure-mode`: name constraints корня расширяются на все имена `.local`. Сертификат сервера содержит занятое имя. Старый корень обрабатывается с подсказкой сбросить его.
- `browser-web-interface`: Host и Origin принимают занятое имя. Вкладка ждёт и сама переподключается. «Запомнить этот браузер» включено по умолчанию. Появляется сообщение о непринятом запомненном входе.
- `event-notifications`: запрос подключения можно разрешить или отклонить из уведомления, с разблокировкой для разрешения.
- `local-history-and-settings`: новая сохраняемая настройка «Имя в сети» с проверкой.

## Impact

- **Android**
  - Новый ответчик mDNS на `MulticastSocket` (224.0.0.251:5353) без сторонних библиотек.
  - `MulticastLock`, пока работает сервер.
  - Новое разрешение `CHANGE_WIFI_MULTICAST_STATE`. Оно выдаётся без запроса пользователю.
  - Правки в `KtorServerRuntimeFactory` (порядок запуска, разрешённые адреса), `ServerEndpoint`, `ServerLifecycleCoordinator`, `LocalCertificateAuthority`/`X509Profiles`, `SecureModeGuard`, `HomeScreen`, `ServerNotificationModel`, `SettingsScreen`, `DataStoreSettingsRepository`, `EventNotificationModel`/`Publisher`/`Actions`.
- **Web**
  - Правки в `sessionController` и `reconnectPolicy` (ожидание сервера), `index.html` (галочка), а также в `failureCatalog`.
- **Протокол:** новых маршрутов нет. В `/web-manifest.json` не добавляются идентификаторы устройства.
- **Документация:** `docs/user-guide.md` (адрес по имени, два телефона) и новый `docs/verification/local-name-and-quick-entry.md`.
- **Проверка:** автоматические тесты не могут проверить, что Windows найдёт имя в настоящей сети Wi-Fi. Для этого нужна ручная проверка на телефоне и компьютере пользователя.
