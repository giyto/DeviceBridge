## Why

Текущий интерфейс DeviceBridge функционален и доступен, но визуально остаётся слишком утилитарным: Android и web не формируют достаточно цельный узнаваемый продукт, постоянная web-шапка расходует полезную высоту, а предупреждение о доверенной сети доминирует даже после того, как пользователь его понял. Нужен отдельный визуальный этап, который повысит качество ежедневного использования и презентационную ценность проекта без изменения локальной архитектуры и модели безопасности.

## What Changes

- Android и web получают единую визуальную систему `Midnight Bridge / Porcelain Bridge`: спокойную premium dark/light палитру, строгую сетку Graphite Professional, ограниченные мотивы Signal Flow, согласованную типографику, поверхности, границы, статусы, иконки и motion.
- Android Home, Text, Files, History и Settings перерабатываются в рамках существующих сценариев: улучшается композиция, плотность, навигация, пустые и рабочие состояния, но команды, данные и protocol behavior не меняются.
- На Android декоративные eyebrow-подписи и повторяющие локальную модель пояснения удаляются из Home, History и Settings; основные заголовки экранов, функциональные секции, статусы и действия сохраняются.
- Android History получает одну скруглённую карточку на строку: файловая запись показывает тип и статус, имя, размер, время и направление без квадратной сетки и без потери действий просмотра/удаления. Тексты и ссылки сохраняют ту же последовательную вертикальную ленту.
- Набор горизонтальных filter chips в History заменяется одной компактной кнопкой с количеством активных фильтров и modal bottom sheet с вертикальными группами «Направление», «Тип» и «Результат», действиями сброса и закрытия; существующая фильтрация и её сохранение не меняются.
- На Android нажатие по свободной области вне активного поля ввода закрывает экранную клавиатуру и снимает focus без потери draft, изменения значения или перехвата нажатий по интерактивным controls.
- Web workspace перерабатывается для desktop, tablet и narrow viewport; постоянная верхняя шапка с логотипом и меткой «Только локально» удаляется полностью и не заменяется другой постоянной полосой.
- Web получает компактное переключение только между `Светлой` и `Тёмной` темами одной кнопкой с иконкой солнца или луны справа в connection area. Выбор сохраняется локально в браузере, применяется до первой отрисовки без вспышки неправильной темы и синхронизируется между вкладками; отдельного режима `Системная` нет, а ранее сохранённое значение `system` мигрирует в `dark`.
- Декоративная подпись «Телефон и компьютер — рядом» и цветная разделительная линия в верхней части web layout удаляются, чтобы первый экран был компактнее и спокойнее.
- После авторизации web показывает реальное имя подключённого Android-устройства вместо технической версии web assets. На Android исходное имя устройства формируется из производителя и модели телефона, остаётся доступным для редактирования и не перезаписывает уже сохранённое пользовательское имя. Точное устаревшее значение `DeviceBridge Android`, созданное прежней версией как стандартное, мигрирует в физическое имя и не считается пользовательским.
- Предупреждение «Используйте только в доверенной сети» остаётся на странице как единая доступная поверхность: при первом использовании оно раскрыто, а нажатием по всей карточке сворачивается в компактную строку и раскрывается обратно без отдельной кнопки и без дополнительного security-help блока. Состояние сохраняется локально и не влияет на сетевые ограничения или защиту.
- На wide web viewport branding/theme area и основная connection/workspace область выравниваются по общей верхней линии; theme icon остаётся в строке с названием продукта, а narrow layout сохраняет естественный одноколоночный порядок.
- Для обеих платформ уточняются состояния default, hover/pressed, focused, disabled, loading, empty, offline, error, success и cancelled, а также поведение при reduced motion, масштабе 200 процентов и длинном содержимом.
- Добавляются visual regression и accessibility проверки светлой/тёмной темы, theme persistence, отсутствия неправильной theme flash, скрытия/возврата предупреждения и отсутствия лишней web-шапки.
- Изменение не добавляет аккаунт, облако, внешний backend, web CDN, внешние шрифты или новую desktop-программу и не меняет существующие API, pairing, session, text или file protocol.

## Capabilities

### New Capabilities

Новые самостоятельные capabilities не добавляются.

### Modified Capabilities

- `android-app-shell`: уточняется визуальный контракт Android-экранов, светлой/тёмной темы, адаптивной композиции, исходного имени реального устройства, History cards/filter sheet, закрытия клавиатуры тапом вне поля и ограниченного Signal Flow feedback.
- `browser-web-interface`: меняются web-композиция без постоянной верхней шапки и декоративной верхней строки, двухрежимный icon theme toggle, показ имени Android-устройства после авторизации и управляемая видимость предупреждения о доверенной сети.
- `error-recovery-and-accessibility`: уточняются контраст, focus, reduced motion, сохранение смысла статусов и доступность скрытого предупреждения во всех темах и размерах.

## Impact

- Android: Compose theme/tokens, reusable UI components, Home, Text, Files, History, Settings, adaptive navigation и UI tests.
- Web: HTML shell, CSS tokens/layout, TypeScript presentation state, локальное хранение theme/warning preferences, responsive и accessibility behavior.
- Проверки: Compose tests, Vitest DOM/contracts, Playwright visual/keyboard/theme suites и ручная матрица Android phone/large-screen и Chrome/Edge.
- Авторизованный status DTO обратно совместимо расширяется полем `deviceName`; network authorization, Room/DataStore/Keystore, file pipeline и остальные protocol flows сохраняются, новые runtime-зависимости не планируются.
